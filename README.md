## 拉片

> 本库自研：全网没找到高星拉片专项库，这张表本身就是差异化价值。

拉片四维拆解表（拿到任何一条爆款视频，按这个拆）：

1. **钩子（0–5 秒）**：第一帧画面是什么？第一句话说什么？为什么让人停下？
2. **节奏**：每几秒一个信息点 / 反转？哪里快、哪里慢？
3. **镜头语言**：景别变化、运镜、转场各用了几次？哪一处是记忆点？
4. **可复用公式**：这条爆款抽象成一句话模板是什么？（例：反常识开头 + 三个证据 + 反转结尾）
