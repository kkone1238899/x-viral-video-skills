## 为什么每个条目都配「怎么用它搞钱」

因为我们的读者是想用 AI 搞钱的人——这是这个系列库的护城河。每个条目只回答两个问题：它能帮你解决什么，谁适合用；以及，怎么用它搞钱。

## 收录标准

- 来源：X 博主实战分享（原帖 / 评论区 / 引用链）及 GitHub 高星项目，每日分时段搜集整理
- 每条格式：一句话（解决什么问题 / 适合谁用）+ 一条「怎么用它搞钱」
- Star 数为 2026-10-10 经 GitHub API 核验；13 个库持续收录中，不一次填满
- 去重：同一项目只收录一次，不堆 raw 链接
- 诚实表述：不写"全网最全 / 第一 / 唯一"这类断言
